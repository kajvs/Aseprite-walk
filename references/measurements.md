# 参考精灵条实测数据（本方法的出处）

被测对象：一张 **288×32** 的行走精灵条（9 帧 × 32×32 单行横排，含正面/背面/侧面三组）。
**该素材是第三方游戏美术，不随本仓库分发。** 本文只记录从它测得的数字与坐标，
用来支撑"整体下移 1 行 + 只改脚"这条规则；不含任何图像资源，也不构成对原素材的再许可。
测法：`templates/probe.lua` + 逐帧配对差异（含"整体下移 1 行"假设），Aseprite 1.3.18.6 无头脚本。

## 1. 帧位布局

| 帧 | 朝向 | 有无脸 |
|---|---|---|
| 1–3 | 正面 | 有 |
| 4–6 | 背面 | 无（头发覆盖）|
| 7–9 | 侧面 | 单眼 |

合成精灵表时必须保持这个顺序：`front 1-3 | back 4-6 | side 7-9`。

## 2. 逐帧包围盒（证明"整图下移 1 行"）

| 帧 | x | y | 高 |
|---|---|---|---|
| 1 | 3..28 | 1..31 | 31 |
| 2 | 3..28 | **0**..31 | **32** |
| 3 | 1..31 | 1..31 | 31 |
| 4 | 4..28 | **0**..31 | **32** |
| 5 | 4..28 | 1..31 | 31 |
| 6 | 4..28 | 1..31 | 31 |
| 7 | 6..26 | 1..31 | 31 |
| 8 | 6..26 | **0**..31 | **32** |
| 9 | 6..26 | 1..31 | 31 |

即：**每组里有一帧从 y0 开始（原图），其余帧从 y1 开始 = 整图下移 1 行、底行被裁掉。**

> 注意样例本身三组的排法并不统一：正面组和侧面组的"原图"在**中间**（2、8），
> 背面组的"原图"在**第一帧**（4）。本 skill 统一成"中间帧 = 原图"。

## 3. 配对差异（证明只有脚在变）

| 配对 | 差异像素 | 说明 |
|---|---|---|
| 帧1 vs 帧2（下移 1 行）| **34 / 1024** | 其余全部吻合，差异全在 y29–31 |
| 帧7 vs 帧8（下移 1 行）| **41 / 1024** | 同上 |
| 帧7 vs 帧9 | **26 / 1024** | 两帧互为"另一只脚抬起" |
| 帧5 vs 帧6 | **24 / 1024** | 同上（背面组）|
| 帧1 vs 帧2（不位移）| 543 | 不做下移就对不上 |

结论：**帧1/3 = 原图整体下移 1 行 + 只改脚。**

## 4. 落地行上的脚（y31）

| 帧 | 脚的 run | 说明 |
|---|---|---|
| 正面帧2 | `x10..14`、`x17..21`，间隙 2px | 双脚分开 |
| 正面帧1 | 左脚 → `x11..15`（+1）；右脚抬起（底行 28–30）| 向中间收 + 少一格 |
| 正面帧3 | 右脚 → `x16..20`（−1）；左脚抬起 | 镜像 |
| 侧面帧8 | `x13..17` 单 run | 双腿并成一根柱子 |
| 侧面帧7/9 | 拆成前后两只脚，中间留 1–2px 透明间隙 | 前后跨步 |

侧面前后脚的细化：帧7 前脚 `x11..13`、后脚 `x16..20`；帧9 前脚 `x11..15`、后脚 `x18..20`。

## 5. 由此提炼的规则

```
帧2 = 原图（逐像素不动）
帧1 = shiftDown(原图, 1) + 两脚各向中间 1px + 抬起的脚少画一行
帧3 = shiftDown(原图, 1) + 两脚各向中间 1px + 另一只脚少画一行
身体（除这 1px 起伏）不动
```

"少画一行"落地成像素：着地脚占 `GROUND-1` 与 `GROUND` 两行；抬起脚只剩 `GROUND` 那一行的内容，
画在 `GROUND-1`，于是 `GROUND` 行空出来——脚下出现一格间隙。

## 6. 复现与校验

```powershell
# 量
cmd /c "`"$ase`" --script-param spr=`"$sprite`" -b --script templates\probe.lua 2>&1"
# 生成（正面/背面）
cmd /c "`"$ase`" --script-param spr=`"$in`" --script-param out=`"$out`" --script-param mode=front --script-param lift=left -b --script templates\make-walk.lua 2>&1"
# 校验：帧2 必须 0 差异；帧1/3 的差异必须只在底部几行
cmd /c "`"$ase`" --script-param a=`"$in`" --script-param b=`"$out.aseprite`" -b --script templates\verify-walk.lua 2>&1"
```
